# Todo List Exercises

This exercises will cover the aspect of data sharing in React by creating a user todo list

## Project Stack

- React
- TypeScript
- Tailwind CSS for styling

## Running the Project

To run the project in your local machine follow the below steps

## What the app will consist

- Adding todo to the list
- Tracking your todo list
- Removing finished tasks

```bash
git clone https://github.com/jabo-arnold-landry/React-todos
cd React-todos
pnpm install # install the project dependencies, but you can also use other package managers to do so pnpm is not mandatory
pnpm run dev
```
